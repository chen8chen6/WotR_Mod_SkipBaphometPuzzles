# WotR_Mod_SkipBaphometPuzzles

	Skip puzzles from Baphomet (and some others).

	Note: This mod is some kind of addon of Puzzle Skip[https://github.com/Balkoth-dev/PuzzleSkip/releases]. To skip Areshkagal's puzzles, you still need [Puzzle Skip] from ArkiveDev and Balkoth.

# Puzzle to Skip

Shield Maze - Four color buttons before Radiance: Solve puzzle by pressing any button. 

Defenders Heart - Three levers in basement: Solve puzzle by taking the shield off wall and pressing the button under it.

Grey Garrison - Six statues before armory: Solve puzzle by interacting with any statue.

Lost Chapel - Desna altar: Summon Arueshalae by interacting with any music instrument.

Citadel Drezen - Rotating Circles before Sword of Valor: Solve puzzle by pressing any button.

Scared Lands - Briges of Nine Colors: Rise all bridges on any button pressed.

Ivory Sanctum - Puzzles of 03456 angles: Solve puzzle by pressing any button.

Midnight Fane - Secret in the Secrets: Open the secret door in main hall by interacting with any door lever.

Purula Fall - Fourteen Fountain: Solve puzzle by touching any fountain(except Cuse, which is a reset button).

Alushynirra - Rotating Platforms: Clear the path to stash by pressing any button.

Gravestone Rock - Four color buttons before Radiance: Solve puzzle by pressing any button.

Ineluctable Prison - Puzzles of 03456 angles: Solve puzzle by pressing any button.

Areelu's Lab - Credle Puzzle: Unlock true ending conditon "You really did pick up my child's favourite belongs first" by touching the credle;

# Installation:

Method 1:

1. Create a new folder named "SkipBaphometPuzzles" under the game mod folder(ex: D:\SteamLibrary\steamapps\common\Pathfinder Second Adventure\Mods\).

2. Unzip the files of "SkipBaphometPuzzles.zip" into the folder you just created.


-- OR --


Method 2:

1. Download and install the UnityModManager

2. Start UnityModManager. Select "Pathfinder: Wrath of the Righteous" for game label. Select game installtion path(ex: D:\SteamLibrary\steamapps\common\Pathfinder Second Adventure\) for folder label. Click "Install" button.

3. Click "Mods" label on top, then click "Install Mods" button. Select "SkipBaphometPuzzles.zip".

# WotR_Mod_SkipBaphometPuzzles

	跳过巴弗灭(顺带还有一些其它人)的解谜.

	注意: 该Mod仅作为Puzzle Skip[https://github.com/Balkoth-dev/PuzzleSkip/releases]的补充, 无法跳过阿什雷卡高的谜题. 需要与ArkiveDev和Balkoth的Puzzle Skip配合使用

# 可跳过的解谜

盾牌迷宫 - 辉光前的四色按钮: 点击任意按钮打开密门.

铁卫雄心 - 地下室的3根拉杆: 摘下墙上的盾牌后, 点击出现的按钮打开密门.

灰兵营 - 军械库前的6个雕像: 点击任意雕像打开密门.

失陷教堂 - 德丝娜祭坛的音乐解谜: 点击任意乐器召唤爱酱.

眷泽城要塞 - 英勇之锋前的旋转地砖: 点击任意按钮解除陷阱.

圣地 - 九色桥梁: 点击任意按钮升起所有桥梁.

象牙迷堂 - 零三四五六角解谜: 点击任意按钮打开密门/显示隐藏宝箱.

午夜庙宇 - 迷中之谜: 点击任意拉杆打开主厅密门.

璞露拉瀑布 - 星座解谜: 点击任意星座(界线除外, 那个是重置按钮)打开密门.

深渊 - 翻转平台: 点击任意按钮铺平通往宝箱的道路.

墓碑岩 - 四色按钮: 点击任意按钮打开密门并解除假宝箱陷阱.

无间囚牢 - 零三四五六角解谜: 点击任意按钮打开密门/显示隐藏宝箱.

阿露瑞实验室 - 触碰顺序: 点击摇篮直接解锁真结局条件"你真的先拿了我孩子最喜欢的东西".

# 安装:

方法1:

1. 在游戏mod目录(例: D:\SteamLibrary\steamapps\common\Pathfinder Second Adventure\Mods\)下创建新文件夹, 命名为SkipBaphometPuzzles

2. 将压缩包内文件解压到该目录下.


-- 或者 --


方法2:

1. 下载并安装UnityModManager.

2. 启动UnityModManager, Game栏选择Pathfinder: Wrath of the Righteous, Folder栏选择游戏安装目录(例: D:\SteamLibrary\steamapps\common\Pathfinder Second Adventure\), 然后点击"Install"按钮.

3. 点击上方"Mods"标签, 选择"Install Mods", 在弹出的对话框中选择"SkipBaphometPuzzles.zip"
